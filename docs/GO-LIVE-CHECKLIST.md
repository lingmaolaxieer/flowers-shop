# 上线验收清单

> 上线前逐项打勾。任一"必须"项未通过，不得发布。

## A. 环境与配置（必须）

- [ ] 服务器已安装 Docker + Compose，端口 80/443/3000/3306/6379 已放行
- [ ] `.env` 中 `JWT_SECRET`、`QR_SIGN_SECRET`、数据库密码均已改为强随机值（非默认值）
- [ ] 已备案域名解析到服务器，HTTPS 证书有效（小程序强制 HTTPS）
- [ ] Nginx 443 server 已配置证书，`/api/` 反代到 api:3000
- [ ] 小程序 AppID/AppSecret 已配置，request 合法域名已加备案域名
- [ ] 手机号快速验证组件已开通
- [ ] 微信支付商户号已绑定，APIv3 密钥/证书序列号/私钥已配置
- [ ] 微信分账权限已开通，分账接收方已添加并审核通过
- [ ] 订阅消息模板已创建，模板 ID 已填入 `.env`
- [ ] 对象存储/CDN 密钥已配置（或明确保留本地存储并记录容量风险）

## B. 数据库（必须）

- [ ] `npm run migration:run` 全部成功后，`migrations` 表记录 M1~M8 全部迁移
- [ ] `npm run seed` 已执行，角色/权限/系统配置/测试账号就位
- [ ] `system_configs.profit_share_max_ratio = 0.3` 已确认
- [ ] 数据库已配置定期备份（如每日 mysqldump + 异地存储）
- [ ] 所有业务表含 tenant_id/supplier_id/shop_id 隔离字段（抽查 5 张）

## C. 功能验收（必须）

### 账号权限
- [ ] 四类角色（批发商/店家/顾客/配送员）可登录并可多身份切换
- [ ] 越权访问返回 403；伪造 tenant_id 字段被剥离
- [ ] 店家入驻审核闭环：提交→人工核验→通过/驳回，通过后自动发放店家身份

### 商品与价格
- [ ] 商品单位（扎/枝/束/箱）、品种/等级/产地/规格/颜色/花期/图片视频可维护
- [ ] 顾客端所有接口/页面**不返回批发价**（抓包验证 /products、/orders 无 wholesalePrice/price/cost 字段）
- [ ] 四层价格（每日/等级/一店一价/阶梯）取价优先级正确
- [ ] 支持预售/每日上新/缺货替换标记

### 库存
- [ ] 库存锁定无超卖（并发下单压测：available 不会为负）
- [ ] 损耗登记后不自动回补库存；库存提醒需人工确认
- [ ] 店家独立库存隔离（A 店下单不影响 B 店库存）

### 订单
- [ ] 顾客单与店家单两条状态机流转合法，非法流转被拒绝
- [ ] 待确认超时（默认 30 分钟）自动取消并释放库存
- [ ] 订单留言/电话/微信客服入口可用

### 二维码出货
- [ ] 一单位一码，编码含防伪签名；篡改二维码被拒绝
- [ ] 重复扫码被拒绝；离线扫码同步幂等（重复同步无重复记录）
- [ ] 蓝牙打印标签真机联调通过（需真实 TSPL 打印机）
- [ ] 扫码记录可导出

### 支付与结算
- [ ] 微信支付下单/回调/退款流程走通（真环境产生真实交易需谨慎，先小额）
- [ ] 回调幂等：重复回调不重复入账
- [ ] 抽成 >30% 时分账模式被强制拒绝并提示转人工
- [ ] 逐花店分账/人工模式切换生效；配送费是否参与抽成配置生效
- [ ] 退款路由正确（分账前/分账后/人工三种）

### 配送与通知
- [ ] 配送费公式正确（基础费+重量费+金额加价−满额减免）
- [ ] 快递/冷链可人工录入运单号
- [ ] 订阅消息可送达；语音提醒接口可替换且调用正常

### 营销
- [ ] 8 类活动（特价/预售/套餐/优惠券/满减/起批量/会员价/积分）可配置
- [ ] 叠加/互斥/优先级规则生效，试算结果可预测

### 对账报表
- [ ] 对账单流程闭环：生成→店家确认→批发审核→导出
- [ ] 8 类报表均可查询并导出 Excel，字段完整

## D. 安全与合规（必须）

- [ ] 所有管理端接口均有 RBAC 权限校验（抽查 10 个）
- [ ] 微信支付回调已验签（真实环境）
- [ ] 防伪签名密钥为强随机串且未提交到代码仓库
- [ ] 小程序《隐私保护指引》已配置（蓝牙/位置用途说明）
- [ ] 操作审计日志正常记录
- [ ] CORS 已限制为可信来源（生产不建议 origin: true）

## E. 交付物（建议）

- [ ] 部署文档、二次开发说明、使用规范、上线检查清单均已归档
- [ ] 全量 TypeScript 编译通过（shared/api/admin）
- [ ] 数据库备份与恢复演练成功一次
- [ ] 已准备回滚方案（保留上一版 dist 与数据库备份）
